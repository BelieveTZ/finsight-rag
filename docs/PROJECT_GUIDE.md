# FinSight-RAG 项目说明

系统在本机从英文财报中检索证据，再根据证据回答数值或业务事实问题。
回答包含文档标识、PDF 页序和原文摘录，可在界面中打开对应页面。

## 问答流程

1. 从完整 PDF 提取页级文本，保留表格标题、单位和来源位置。
2. BGE 向量检索寻找语义相关片段，BM25 检索匹配财务术语；混合方案通过 RRF 合并排名。
3. 按长度预算与问题类型选择证据，将证据交给本地 Qwen3-8B。
4. 检查问题范围、单位、片段标识、页码和引文是否存在，展示答案或拒答。
5. 将模型服务错误单独显示。拒答只表示当前问题或证据不足，不能证明整份报告没有答案。

## 代码阅读

先看 `data/corpus.json` 中的文档标识、来源和校验值，再查看
`scripts/rag.py` 的 `answer_question`，跟踪检索、证据选择、生成与校验。
`scripts/answer_guards.py` 负责输出检查，`scripts/app.py` 提供本地界面。
`scripts/portfolio_eval.py` 负责开发与最终评测，并校验冻结配置。

可结合 `artifacts/rag/20260919T051129788925Z.json` 查看一次真实运行中
资本支出回答与固定资产拒答的完整路径。各模块职责见[架构说明](ARCHITECTURE.md)。

## 结果与限制

四份完整财报共 997 页、2,245 个片段。24 道数值题和 6 道拒答题按文档划分，
3M、PepsiCo 用于开发，AMD、CVS Health 用于最终评测。
最终 12 道数值题的固定数值匹配为纯向量 5/12、混合 9/12；
同时要求引用直接支持时为 5/12、8/12。

检索命中不保证生成正确，引文确实存在也不保证它支持所问指标。
表格列错位、每股指标与总额混淆、非目标年度及题目口径歧义均出现在实测中。
两条业务/风险事实演示的证据已复核，尚无独立的文本问答测试集。
首次界面请求包含建索引与加载模型，约 121 秒；不能与预热后的时延混用。

完整规则与逐题结果见[评测报告](EVALUATION.md)、[来源复核](SOURCE_REVIEW.md)
和[失败分析](FAILURE_ANALYSIS.md)。本机复现步骤见[Windows 操作说明](LOCAL_SETUP.md)。
