# FinSight-RAG

面向中文上市公司年报的、**评测驱动（evaluation-first）**的 RAG 研究助手。它不只回答问题，还会给出页码级证据、调用计算工具处理财务指标，并用可复现实验对比不同检索和生成方案的准确率、延迟与成本。

> 当前状态：Milestone 0 — 仓库与开发环境骨架。

## 为什么做这个项目

普通“上传 PDF 后聊天”的项目同质化严重。FinSight-RAG 要展示一条完整的 AI 工程链路：

1. PDF/表格解析、清洗、切分与数据质量检查；
2. BM25 + dense retrieval 的混合检索；
3. cross-encoder reranker 与检索消融实验；
4. 带页码引用的生成、拒答与幻觉检测；
5. 计算器/财务指标工具调用和简单 Agent 工作流；
6. 自动评测、延迟/Token/成本统计；
7. FastAPI、Web Demo、Docker 与测试。

目标岗位：大模型应用算法工程师、RAG/Agent 算法工程师、机器学习工程师、AI 应用研发工程师。

## 最终演示

用户可以选择一家公司的年报并提出：

- “2023 年和 2024 年的研发费用分别是多少，同比增长多少？”
- “公司认为最主要的三项经营风险是什么？逐条附上原文页码。”
- “如果年报中没有披露该指标，明确拒答，不允许猜测。”

系统返回结构化答案、计算过程、证据片段和页码；评测面板展示 Recall@K、MRR、答案正确率、引用命中率、拒答准确率、P95 延迟和平均成本。

## 快速开始

要求 Python 3.11 或更高版本。

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
finsight doctor
pytest
```

如果最后两条命令通过，Milestone 0 即完成。

## 项目原则

- **先基线，后复杂化：** 每次升级都必须用指标证明有效。
- **先可复现，后堆框架：** 核心检索逻辑尽量可读，框架只是工具。
- **数据集与 Demo 分离：** 小型公开样本保证任何人都能复现，更多年报只用于演示。
- **不把 LLM-as-a-judge 当唯一真相：** 同时使用人工标注、确定性指标和错误分析。
